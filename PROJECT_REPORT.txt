2. ОБЩИЕ СВЕДЕНИЯ О ПРОЕКТЕ
--------------------------------------------------------------------------------

Название проекта: VehicleLogbook (Журнал автомобиля / Fuel Log)
Тип приложения: Android
Язык программирования: Kotlin
UI Framework: Jetpack Compose
Архитектура: MVVM + Clean Architecture

Описание проекта:
Android-приложение для отслеживания заправок и обслуживания автомобиля с 
расчётом расхода топлива. Позволяет пользователям:
  - Записывать покупки топлива с показаниями одометра, типом топлива, литрами и ценой
  - Отслеживать записи об обслуживании с несколькими позициями (запчасти/работа)
  - Просматривать статистику: общий пробег, средний расход топлива, общие расходы
  - Управлять профилем одного автомобиля (марка, модель, год, текущий пробег)

entity/Converters.kt

Таблица: fuel_records (Заправки)
---------------------------------
CREATE TABLE fuel_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date TEXT NOT NULL,              -- LocalDate в ISO формате (YYYY-MM-DD)
    odometer INTEGER NOT NULL,       -- Пробег на момент заправки
    fuel_type TEXT NOT NULL,         -- Тип топлива (AI-95, AI-98 и т.д.)
    liters REAL NOT NULL,            -- Количество литров
    price_per_liter REAL NOT NULL,   -- Цена за литр
    total_price REAL NOT NULL,       -- Общая сумма покупки
    full_tank BOOLEAN DEFAULT 0,     -- Флаг "Полный бак"
    average_consumption REAL,        -- Расход топлива (л/100км) - рассчитывается
    created_at INTEGER               -- Timestamp создания записи
);

Таблица: service_records (Обслуживание)
----------------------------------------
CREATE TABLE service_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date TEXT NOT NULL,              -- Дата обслуживания
    odometer INTEGER NOT NULL,       -- Пробег на момент обслуживания
    notes TEXT,                      -- Примечания к услуге
    total_price REAL NOT NULL,       -- Итоговая сумма услуги
    created_at INTEGER               -- Timestamp создания записи
);

Таблица: service_items (Элементы обслуживания)
-----------------------------------------------
CREATE TABLE service_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    service_id INTEGER NOT NULL REFERENCES service_records(id),  -- FK к записи
    name TEXT NOT NULL,              -- Название запчасти/услуги
    part_number TEXT,                -- Артикул/номер детали
    quantity REAL NOT NULL,          -- Количество
    unit_price REAL NOT NULL,        -- Цена за единицу
    total_price REAL NOT NULL        -- Итого (quantity × unitPrice)
);

Таблица: vehicle (Профиль автомобиля)
--------------------------------------
CREATE TABLE vehicle (
    id INTEGER PRIMARY KEY DEFAULT 1,
    make TEXT NOT NULL,              -- Марка (например, "Toyota")
    model TEXT NOT NULL,             -- Модель (например, "Camry")
    year INTEGER,                    -- Год выпуска
    odometer INTEGER NOT NULL,       -- Текущий пробег
    updated_at INTEGER NOT NULL      -- Timestamp последнего обновления

4. КЛЮЧЕВАЯ БИЗНЕС-ЛОГИКА
================================================================================

1. РАСЧЁТ РАСХОДА ТОПЛИВА
   -----------------------
   Условие: работает только если предыдущая запись была отмечена как "Полный бак"
   
   Формула:
     consumption = (liters × 100) / (currentOdometer - previousOdometer)
   
   Пример:
     Предыдущий пробег: 50000 км, предыдущая заправка: полный бак
     Текущий пробег: 52000 км, текущая заправка: 40 литров
   
     consumption = (40 × 100) / (52000 - 50000) = 4000 / 2000 = 2.0 л/100км

2. РЕЖИМЫ ВВОДА ЦЕНЫ
   ------------------
   Режим "По литру":
     Пользователь вводит: количество литров + цена за литр
     Система рассчитывает: total_price = liters × price_per_liter
   
   Режим "Общая сумма":
     Пользователь вводит: общее количество литров + общую сумму
     Система рассчитывает: price_per_liter = total_price / liters

3. ЭЛЕМЕНТЫ УСЛУГ (ОБСЛУЖИВАНИЕ)
   ------------------------------
   Одна запись обслуживания может содержать несколько элементов:
   
   - Название запчасти/услуги
   - Артикул (опционально)
   - Количество
   - Цена за единицу
   
   Итоговая сумма услуги = Σ(quantity × unitPrice) для всех элементов

4. СРЕДНИЙ РАСХОД ТОПЛИВА (ОБЩИЙ)
   --------------------------------
   Рассчитывается как взвешенное среднее от всех записей с расходом:
   
     average_consumption = Σ(consumption_i × liters_i) / Σ(liters_i)
